Filter the records by Code so that only rows whose code matches the pattern AA-0000 are processed: exactly two uppercase letters, a hyphen, and four digits. Use the FlowBlox filtering and condition components; do not hardcode individual allowed codes.

For every matching row, create a JSON item containing Code, Description, and Amount. Collect all matching items in a top-level JSON array named Results and write the result to $Project::OutputDirectory\filtered-records.json.
